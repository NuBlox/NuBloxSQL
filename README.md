# NuBloxSQL

**Definition-first restart — 18 October 2026**

**NuBloxSQL is a proprietary, vendor-aware database technology platform built around a universal native Driver, with Shell and Workbench applications for the entire database lifecycle.**

The product definition remains under founder review. The repository now includes an **experimental independent first-party native MySQL Driver slice**, not a finished universal platform. Earlier implementations remain in protected/historical archives.
